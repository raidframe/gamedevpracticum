# Структура проекта

```text
Assets/
  Art/Models/
    Cases/             BlueFlame, Hotrod, RepairableBlueFlame
    Components/        CPU, GPU, RAM, Motherboard, PowerSupply,
                       CaseFan, CPUCooler, HDD, SSD
    Furniture/         Table, Chair
    Peripherals/       Keyboard, Mouse
    Environment/      SecurityCamera
  Materials/           Материалы прототипа
  Scenes/              Игровая сцена RepairPrototype и исходная SampleScene
  Scripts/             Игровой код
  Settings/            URP и профили рендеринга
ArtSource/             Отдельные авторские исходники и проверочные рендеры
Docs/                  Описание и инструкции по проверке
Packages/              Зависимости Unity
ProjectSettings/       Настройки проекта
```

Внутри наборов моделей сохранено расположение исходников, текстур и материалов. Все перемещения выполнены вместе с `.meta`, GUID сохранены. FBX ремонтируемого корпуса теперь находится вместе с его атласом и материалом в `Cases/RepairableBlueFlame`.

Удалены пять резервных `.blend1` с их `.meta`, учебная папка `TutorialInfo`, шаблонный `Readme.asset` и пустая папка исходников мыши. Разные варианты моделей и текстуры сохранены. Файлы с именем `preview` не удалены: некоторые уже используются материалами.

`SampleScene` сохранена: она указана в `ProjectSettings` как сцена шаблона. Input Actions и настройки рендеринга также сохранены, поскольку на них есть ссылки из настроек проекта. Существующие изменения `RepairPrototype.unity` не затрагивались.

В нескольких исходных `.blend` ещё до уборки были пути к отсутствующим внешним изображениям: PSU, AMD GPU, Samsung SSD, DDR3, обе материнские платы, клавиатура и GPU 1050ti v2. Часть этих записей может быть неиспользуемыми изображениями Blender; это не доказательство ошибки отображения. Два найденных существующих внешних изображения (`mat1.png`, `Mat2.png`) перенесены вместе с их моделями, относительные пути сохранены. Проверка материалов в Unity остаётся отдельным шагом.

Unity автоматически создаёт `Library`, `Temp`, `Logs`, `UserSettings`, а IDE — `.vs`, `.csproj` и `.sln`. Эти служебные файлы исключены из Git и оставлены на диске, чтобы не вызывать лишний переимпорт и не мешать открытому редактору.

Для будущих перемещений используй окно Project в Unity: оно переносит `.meta` автоматически. Исходники `.blend` внутри Assets пока служат импортируемыми моделями — не переносить их за пределы Assets без предварительной замены на FBX в сценах.
