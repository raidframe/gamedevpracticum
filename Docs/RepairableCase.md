# Ремонтируемый корпус PC_PSX

## Результат

- `ArtSource/PC_PSX_Repairable/PC_PSX_Repairable.blend` — редактируемая модель с закрытой крышкой и упакованной текстурой.
- `Assets/Art/Models/Cases/RepairableBlueFlame/PC_PSX_Repairable.fbx` — экспорт для Unity без камер и света; рядом атлас и `.meta`.
- `ArtSource/PC_PSX_Repairable/closed.png` и `open.png` — проверочные рендеры.
- `ArtSource/PC_PSX_Repairable/validation.json` — результаты проверок.

Исходный PC_PSX.blend не изменён (проверено SHA-256). Игровая сцена не редактировалась.

## Устройство

`SidePanel` — отдельная левая крышка с сохранённой UV-развёрткой и рисунком. `SidePanel_Grille` — её дочерняя решётка. За крышкой нет дублирующей стенки. Стенки получили толщину 1,5 мм и нейтральную внутреннюю поверхность.

Добавлены четыре рейки каркаса, площадка материнской платы с девятью условными стойками, верхняя задняя полка PSU с опорами и передние направляющие привода. Это игровая заготовка, не точная механическая спецификация ATX.

В `ComponentMounts` находятся ориентиры для материнской платы, PSU, GPU, двух планок RAM и привода. Существующие модели деталей ещё не примерялись. Масштаб Empty задаёт размер визуальной рамки, его не следует копировать на устанавливаемую деталь.

Габариты: ширина 20 см, глубина 44,3 см, высота 45,9 см. 23 mesh-объекта, 716 треугольников. В Blender перед направлен по -Y, верх по +Z, крышка снимается по -X.

## Проверка в Blender

1. Открой новую модель, включи Material Preview.
2. Выбери `SidePanel` в коллекции `PC_PSX_Repairable`.
3. Нажми G, X, введи -0.23, Enter. Крышка должна отойти вместе с решёткой, открывая внутренний отсек.
4. Ctrl+Z возвращает её на место. Закрытая позиция: (-0.096, 0, 0.235) м.
5. Включи отображение Empty, чтобы видеть ориентиры компонентов.

## Проверка в Unity

Импорт в Unity в этой итерации не проверялся. Добавь новый FBX в тестовую сцену, проверь масштаб и материалы URP. Если потребуется, создай материалы URP/Lit и назначь атлас в Base Map. У атласа настроена точечная фильтрация. Проверь отдельное перемещение SidePanel с решёткой; учитывай преобразование осей при экспорте FBX.

Коллайдеры, анимация открытия, скрипт взаимодействия и установка компонентов пока не добавлены.
